## 👋 Welcome to WhereIsJaeyoon

Building low-level systems, real-time graphics pipelines, and cross-platform tools.

---

### 📂 Featured Repositories

| Repository | Description | Tech Stack |
| :--- | :--- | :--- |
| **[ascii-cam](https://github.com/whereisjaeyoon/ascii-cam)** | Virtual webcam device built with Windows Media Foundation, applying real-time visual filters via HLSL shaders alongside a Rust client. | `C++` `Windows SDK` `Media Foundation` `HLSL` `Rust` |
| **[SlimeDisplay](https://github.com/whereisjaeyoon/SlimeDisplay)** | Cross-platform virtual display streaming over LAN using WebRTC and a browser client, built on Windows VDD and macOS `CGVirtualDisplay`. | `WebRTC` `WebSocket` `mDNS` `TypeScript` `C++` |

---

### 🛠 Focus Areas

- **Virtual Devices & Graphics:** Windows Media Foundation virtual cameras, Windows VDD/IddCx integration, HLSL compute/pixel filters, and macOS `CGVirtualDisplay`.
- **Real-Time Streaming:** Hardware-accelerated capture and encoding streamed over WebRTC with WebSocket signaling, mDNS/DNS-SD discovery, and QR pairing.
- **Cross-Platform Clients:** Native and web clients targeting desktop, mobile, and browser environments.
